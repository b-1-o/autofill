# Demo Assets

This directory is for portfolio/demo media only.

## Demo GIF

Record a short ~15 second demo with ScreenToGif, Loom, or another screen recorder.

Suggested scenario:

1. Open a LinkedIn Easy Apply application.
2. Click the Autofill extension icon.
3. Click **Fill Form**.
4. Show the form fields being populated.
5. Show the fill report and manual review step.

Save the final recording as:

`assets/demo.gif`

Keep the GIF at **5 MB or less**.

## Popup screenshot

Capture the extension popup and save it as:

`assets/popup.png`

Recommended screenshot content:

- Profile fields
- Fill Form button
- Fill report
- Cover-letter template / AI placeholder

## Repository hygiene

Do not commit private documents or other sensitive files.

In particular:

- Do not commit PDFs.
- Do not commit ZIP archives.
- Do not commit API keys.
- Do not commit session tokens.

The repository .gitignore already excludes `*.pdf` and `*.zip`.
